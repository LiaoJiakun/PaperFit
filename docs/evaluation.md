合成样例使用固定响应，验证了分组、修正次数、异常隔离和报告生成。浏览器实测了离线流程和 Markdown 下载。另用模拟的 DeepSeek 响应验证了「我的论文」入口，确认编辑后的标准用于上传文件的批量筛选。Rojas 样例使用已知引文，验证了 PDF 文本提取和定位。此前的单篇 CLI 已成功调用过 DeepSeek。

2026-11-05 用 DeepSeek 实测新版批量筛选。标准建议请求成功。先处理损坏的 D，再处理真实的 Rojas PDF 和合成 A、B。D 被标为「待人工核查」，Rojas 和 A 为「优先读」，B 为「背景参考」。三个可读文件各有三条引文通过页码定位。这批只有一篇真实论文，属于集成验证。

真实论文评测可以选 3～5 篇，同时包含直接相关、部分相关和低相关案例。先人工标注每篇优先级、理由和证据页，再运行 PaperFit。记录优先级一致数/论文数、证据支持判断数/人工复核条数、处理失败数及原因。同一个人按同一份标准对两组相近难度的论文计时，分别使用手动筛选和 PaperFit，记录从打开文件到给出阅读清单的耗时。当前没有多篇真实论文的准确率或节省时间测量。
